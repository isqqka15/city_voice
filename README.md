# City Voice

City Voice — приложение на Flutter для создания и просмотра обращений о городских проблемах. В текущей версии данные заявок сохраняются на устройстве; серверная синхронизация не реализована.

## Возможности

- Создание и редактирование заявок с названием, описанием, категорией, датой, местоположением и прикреплёнными изображениями.
- Выбор местоположения вручную или получение координат устройства при наличии разрешения.
- Локальное сохранение, редактирование и удаление заявок; фильтрация по категориям и статусам, сортировка по дате.
- Сохранение черновиков на устройстве с возможностью продолжить редактирование.
- Интерфейс на английском, русском и казахском языках; язык устройства выбирается автоматически при первом запуске, если он поддерживается.
- Светлая, тёмная и системная темы оформления.
- Экран часто задаваемых вопросов и форма обращения в поддержку.
- Экраны входа и регистрации по электронной почте или телефону.

Для регистрации по электронной почте принимаются адреса Gmail и Googlemail; минимальная длина пароля — 8 символов. Аутентификация использует локальные демонстрационные данные. Подтверждение по телефону не отправляет SMS. Серверная регистрация, доставка обращений в поддержку и межустройственная синхронизация не настроены. Не используйте эту версию для обработки реальных учётных данных или отправки обращений в городские службы.

## Технологии

- Flutter и Dart
- Provider для управления состоянием
- Hive для локального хранения заявок
- SharedPreferences для локального хранения черновиков и пользовательских настроек
- Image Picker для выбора изображений
- Geolocator и Permission Handler для получения координат с разрешения пользователя
- Flutter Localizations и ARB-файлы для локализации

## Требования

- Flutter SDK с Dart SDK версии 3.10.1 или новее, совместимой с ограничением проекта в `pubspec.yaml`
- Android Studio и Android SDK для запуска или сборки под Android
- macOS и Xcode для сборки под iOS

## Установка и запуск

```bash
git clone https://github.com/isqqka15/city_voice.git
cd city_voice
flutter pub get
flutter run
```

Перед запуском проверьте доступные устройства командой:

```bash
flutter devices
```

## Сборка

Сборка APK для Android:

```bash
flutter build apk --release
```

Готовый APK будет создан по пути `build/app/outputs/flutter-apk/app-release.apk`.

Сборка Android App Bundle:

```bash
flutter build appbundle --release
```

Сборка iOS доступна на macOS с установленным Xcode:

```bash
flutter build ios --release
```

## Проверка

flutter test
