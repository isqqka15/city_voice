# City Voice App - Полная Документация

## 📱 Обзор Проекта

**City Voice App** - это современное, полностью локализованное мобильное приложение на Flutter, разработанное для платформ iOS и Android. Приложение позволяет пользователям сообщать о гражданских проблемах, делиться обновлениями со своим сообществом и участвовать в местном управлении через интуитивный многоязычный интерфейс.

**Версия:** 1.0.0+1  
**Framework:** Flutter 3.10.1+  
**Платформы:** iOS и Android  
**Поддерживаемые языки:** Английский, Русский, Казахский

---

## 🎯 Основные Функции

### 1. **Аутентификация и Авторизация**
- **Email аутентификация** - Валидация только Gmail с проверкой в реальном времени
- **Телефонная аутентификация** - SMS-верификация с 6-значным кодом
- **Гостевой доступ** - Просмотр приложения без регистрации
- **Сохранение сеансов** - Пользователь остаётся в системе после перезагрузки
- **Управление паролями** - Требование минимум 8 символов с валидацией

**Экраны аутентификации:**
- Welcome Screen - Начальная страница
- Auth Method Selection - Выбор Email или телефонной аутентификации
- Authentication Screen - Вход/Регистрация с проверкой в реальном времени
- Verification Screen - Верификация SMS кода с обратным отсчётом

### 2. **Поддержка Множества Языков**
- **Автоматическое определение** - Использует язык системы устройства при первом запуске
- **Сохранение выбора** - Выбор пользователя сохраняется между сеансами
- **Три поддерживаемых языка:**
  - English (en) - Резервный язык
  - Russian (ru) - Русский
  - Kazakh (kk) - Казахский
- **Легко расширяемо** - Простой процесс добавления новых языков
- **Типобезопасная локализация** - Отсутствие ошибок во время выполнения

**Доступ к переводам:** `context.l10n.ключ_строки` через пользовательское расширение

### 3. **Управление Темами**
- **Три режима темы:**
  - Auto - Следует системным настройкам
  - Light - Светлый интерфейс
  - Dark - Тёмный режим для глаз
- **Сохранение выбора** - Предпочтение темы сохраняется
- **Material Design 3** - Современный единый дизайн
- **Доступная палитра:**
  - Light: Натуральные коричневые и белые тона
  - Dark: Глубокий чёрный с лёгкими акцентами
  - WCAG AA соответствие контрастности

### 4. **Отчёты и Социальная Лента**
- **Создание отчётов** - Отправка гражданских проблем с текстом и изображениями
- **Лента отчётов** - Просмотр отчётов сообщества с бесконечной прокруткой
- **Интерактивные элементы:**
  - Лайки/Дизлайки отчётов
  - Комментарии к проблемам
  - Поделиться отчётом
  - Развёртывание длинного текста
- **Обновления в реальном времени** - Функция обновления при потягивании
- **Временные метки** - Человеческий формат относительного времени
- **Аватары пользователей** - Визуальная идентификация с инициалами

### 5. **Управление Черновиками**
- **Автосохранение** - Никогда не потеряйте несохранённые отчёты
- **История черновиков** - Просмотр и управление всеми сохранёнными черновиками
- **Быстрое возобновление** - Продолжите редактирование начатых отчётов
- **Локальное хранилище** - Все черновики безопасно хранятся на устройстве

### 6. **Параметры и Предпочтения**
- **Профиль пользователя** - Просмотр и управление информацией об аккаунте
- **Выбор языка** - Переключение между English, Russian, Kazakh
- **Переключение темы** - Переключение между Light/Dark/Auto режимами
- **FAQ и Поддержка** - Полная документация справки
- **Управление аккаунтом** - Выход и восстановление аккаунта

## 🌐 Локализация

### Добавление нового языка

1. **Добавьте код языка в Locale Provider:**
   ```dart
   // lib/providers/locale_provider.dart
   List<Locale> getSupportedLocales() {
     return [
       Locale('en'),
       Locale('ru'),
       Locale('kk'),
       Locale('fr'), // Новый язык
     ];
   }
   ```

2. **Создайте файл локализации:**
   ```dart
   // lib/l10n/app_localizations_fr.dart
   class AppLocalizationsFr extends AppLocalizations {
     @override
     String get appTitle => 'City Voice';
     @override
     String get email => 'E-mail';
     // ... все строки переводов
   }
   ```

3. **Обновите App Localizations:**
   ```dart
   // lib/l10n/app_localizations.dart
   static AppLocalizations of(BuildContext context) {
     switch(locale.languageCode) {
       case 'fr':
         return AppLocalizationsFr();
       // ... другие языки
     }
   }
   ```

### Доступ к переводам

```dart
// Использование расширения (рекомендуется)
String email = context.l10n.email;

// Прямое использование AppLocalizations
String password = AppLocalizations.of(context)!.password;
```

## 🔐 Детали аутентификации

### Правила валидации Email
- **Формат:** Должен быть действительный email
- **Провайдер:** Только Gmail (gmail.com, googlemail.com)
- **Сообщения об ошибках:** Локализованы на 3 языках

**Процесс валидации:**
```
Пусто?      → "Email обязателен"
Неверно?    → "Пожалуйста, введите действительный email"
Не Gmail?   → "Пожалуйста, используйте Gmail адрес"
Действителен → ✓ Принято
```

### Требования к пароли
- **Минимальная длина:** 8 символов
- **Подтверждение:** Должны совпадать при регистрации
- **Хранение:** Безопасно зашифрован (production)
- **Показать/скрыть:** Переключение видимости поля ввода

### Телефонная аутентификация
- **Формат:** Поддерживается международный формат (+1-555-0000)
- **Верификация:** SMS с 6-значным кодом
- **Таймаут:** 60-секундный лимит на повторную отправку
- **Попытки:** Неограниченные с ограничением скорости (production)

## 🐛 Решение проблем

### Часто встречаемые проблемы

**Приложение не запускается**
- Очистить кэш сборки: `flutter clean`
- Переустановить зависимости: `flutter pub get`
- Запустить генерацию кода: `flutter pub run build_runner build`

**Язык не меняется**
- Проверить инициализацию locale provider в main()
- Проверить SharedPreferences на сохранённую локаль
- Подтвердить что AppLocalizations.of() использует правильную локаль

**Тема не сохраняется**
- Убедиться что ThemeProvider.initialize() вызывается в main()
- Проверить SharedPreferences на сохранённый режим темы
- Проверить что MaterialApp получает themeMode от provider

**Ошибки сборки**
- Проверить версию Flutter: `flutter --version`
- Проверить Android SDK: `flutter doctor`
- Очистить сборку: `flutter clean && flutter pub get`
